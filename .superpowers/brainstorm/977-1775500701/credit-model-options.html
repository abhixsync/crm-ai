Key finding from code analysis

Each AI call = 1 CALL_SCRIPT + N CALL_TURNs (avg 3–4, max 12) + 1 CALL_SUMMARY.
Your tenants use their own Twilio/Vonage/Plivo credentials — so telephony costs go to them directly.
AI costs (Groq/Gemini) are nearly free. Credits are really about metering + upsell, not cost recovery.
A

Flat Per-Call Current model, renamed

1 credit per call initiated, regardless of duration or turns.

✓ Zero new code (just fix broken increment)
✓ Simplest mental model
✗ 2-min call = 15-min call (unfair)
✗ No benefit over current plan limits
Example: 2-min call = 1 credit  |  10-min call = 1 credit
C

Hybrid: Initiation + Per-Minute ⭐ Recommended

Flat credits to connect a call, then credits per minute of actual duration.

✓ Reflects real usage (longer call = more credits)
✓ durationSecs already captured in CallLog
✓ Familiar model (like mobile call billing)
✓ Pre-check possible: block if < initiation fee
✗ Deduction happens after call ends (webhook)
✗ Slight implementation complexity vs Option A
Formula: credits = 2 (init) + ⌈duration_mins⌉
2-min call = 4 credits  |  5-min call = 7 credits  |  10-min call = 12 credits
B

Per AI Turn

1 credit per LLM invocation: CALL_SCRIPT (1) + each CALL_TURN (1 each) + CALL_SUMMARY (1).

✓ Most technically accurate
✓ Incentivises shorter AI responses
✗ Unpredictable for users (5–14 credits per call)
✗ Requires tracking in 3 places (trigger + webhook×2)
✗ Webhook complexity; hard to pre-check limit
Example: Short call (3 turns) = 5 credits  |  Long call (12 turns) = 14 credits

Why Option C (Hybrid) is recommended

1. Tenants pay their own telephony
Twilio charges go to them. Your AI cost (Groq/Gemini) is tiny. Credits are a metering tool — duration is the fairest meter.
2. Duration already in the DB
CallLog.durationSecs is already populated from Twilio webhook. No adapter changes needed.
3. Familiar to users
"You pay to connect + per minute" is the same model every telecom uses. Zero learning curve.
4. Easy to upgrade later
Start with hybrid. Later add an AI-turn multiplier (e.g. 1 extra credit per 3 turns) without changing the mental model.
