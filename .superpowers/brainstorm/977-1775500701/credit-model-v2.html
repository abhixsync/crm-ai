A

Flat Per-Call Current model, renamed

1 credit per call initiated, regardless of duration or turns.

✓ Zero new code (just fix broken increment)
✓ Simplest mental model
✗ 2-min call = 15-min call (unfair to short calls)
✗ No real benefit over current plan limits
Example: 2-min call = 1 credit  |  10-min call = 1 credit
C

Hybrid: Initiation + Per-Minute ⭐ Recommended

Flat credits to connect a call, then credits per minute of actual duration.

✓ Reflects real usage — longer call costs more
✓ durationSecs already in CallLog (from Twilio webhook)
✓ Familiar model (like mobile call billing)
✓ Can pre-check credit balance before connecting
✗ Final deduction happens after call ends (webhook)
✗ Slightly more complex than Option A
Formula: credits = 2 (init) + ⌈duration_mins⌉
2-min call = 4 credits  |  5-min call = 7 credits  |  10-min call = 12 credits
B

Per AI Turn

1 credit per LLM call: CALL_SCRIPT (1) + each conversation turn + CALL_SUMMARY (1).

✓ Most technically accurate
✓ Incentivises shorter AI responses
✗ Unpredictable for users (5–14 credits per call)
✗ Must track in 3 places (trigger + webhook × 2)
✗ Hard to pre-check credit limit mid-conversation
Example: Short call (3 turns) = 5 credits  |  Long call (12 turns) = 14 credits
